# История изменений

## 2.3.5

- Ускорено ручное переключение: убрана пауза 1,2 секунды, проверка пинга выполняется в фоне после подтверждения запуска службы.
- Интерфейс обновляет изменившиеся строки без повторной загрузки всех подключений. Сохраняются фильтр, сортировка и раскрытые параметры.
- На время применения показано «Переключение…», повторные нажатия заблокированы. В уведомлении отображается время активации; API возвращает замеры её этапов.
- Сохранены проверка конфигурации, контроль запуска службы и откат при ошибке.
- Проверки: 109 автоматических тестов; браузерная проверка на демонстрационных данных, включая список из 532 подключений. Подробности — `docs/TESTING-2.3.5.md`.

## 2.3.4

- Исправлен ложный отказ Xray при активации подключений: валидатор передаёт каталог geodata через XRAY_LOCATION_ASSET. Явно заданный путь сохраняется; иначе определяется каталог dat рядом с конфигурациями или стандартный каталог установки.
- Проверка по-прежнему выполняется на временной копии, без изменения рабочих файлов и перезапуска службы.
- Проверки: 101 автоматический тест; новый валидатор проверен установленным Xray на роутере — конфигурация Бельгии принята, контрольные суммы рабочих файлов не изменились.
- Подробности — `docs/TESTING-2.3.4.md`.

## 2.3.3

- Убрана лишняя нижняя кнопка «Закрыть» на вкладке «Резервная копия». Окно закрывается крестиком в шапке или Escape.
- Проверки: 97 автоматических тестов и проверка закрытия окна в браузере.

## 2.3.2

- Исправлены скачки окна настроек при переключении вкладок: размер окна фиксирован, шапка и навигация остаются на месте.
- Содержимое вкладки прокручивается отдельно; при смене вкладки прокрутка возвращается к началу.
- Кнопки вкладок имеют одинаковый размер на компьютере и телефоне.
- Проверки: 97 автоматических тестов, все вкладки настроек на четырёх размерах экрана и клавиатурная навигация. Подробности — `docs/TESTING-2.3.2.md`.

## 2.3.1

- Исправлено имя Default у старого импортированного подключения: после привязки к подписке используется название сервера и соответствующий флаг. Активное подключение и настройки сохраняются.
- Добавлена кнопка «Остановить» при массовой проверке пинга. Текущий запрос завершается, остальные не запускаются; результаты сохраняются, проверку можно запустить снова.
- Панель кнопок переносится на узких экранах без горизонтальной прокрутки.
- Проверки: 97 автоматических тестов и проверка интерфейса. Подробности — `docs/TESTING-2.3.1.md`.

## 2.3.0

- Сохранены одинаковые размеры вкладок и положение шапки. Добавлена видимая клавиатурная фокусировка переключателей и поддержка уменьшения анимации.
- README и скриншоты обновлены на демонстрационных данных.
- Проверки: 92 автоматических теста, четыре вкладки на пяти ширинах экрана, редакторы и клавиатурная навигация. Подробности — `docs/TESTING-2.3.0.md`.

## 2.2.5

- Проверка и установка обновлений из публичного GitHub работают без токена. Токен остаётся необязательным для приватных репозиториев.
- Файлы публичного обновления загружаются по закреплённому SHA коммита с проверкой контрольных сумм; это сокращает расход лимита GitHub API.
- При исчерпании лимита GitHub показано сообщение с предложением повторить проверку позже.
- Исправлено отклонение обновления из-за вложенных каталогов ресурсов, включая папку шрифтов.
- В README добавлена прямая команда скачивания и запуска скрипта удаления, обновлены способы обновления без токена.
- Проверки: 92 автоматических теста; подробности — `docs/TESTING-2.2.5.md`.

## 2.2.4

- В README описаны действия установщика, обновление через SSH и веб-интерфейс, удаление панели и сохранение данных.
- В README добавлена команда установки публичного репозитория через SSH Entware; уточнено требование токена для встроенной проверки обновлений.
- Устранено смещение шапки при переключении между короткими и длинными вкладками: место под вертикальную прокрутку сохраняется.
- Четыре основные вкладки имеют одинаковые размеры; активная рамка не меняет геометрию. На телефонах вкладки размещаются в два ряда.
- Добавлен заголовок «Пинг» над задержкой в списках LTE и обычных серверов.
- Исправлены замечания QA B01 и B02: Tab и Shift+Tab удерживают фокус внутри модального окна, Escape закрывает его и возвращает фокус на вызвавшую кнопку.
- Исправлено замечание B03: актуализированы версия, число тестов и ссылка на отчёт в README; обновлены версии ресурсов интерфейса.
- Проверки: 89 автоматических тестов, переключение вкладок на пяти ширинах экрана, клавиатурная проверка редактора подписки и сверка конфигураций Xray. Подробности — `docs/TESTING-2.2.4.md`.

## 2.2.0

- Вход по локальному ключу, сессионная cookie, защита API от запросов с чужого сайта.
- Применение конфигурации через общую очередь с проверкой и откатом файлов при ошибке.
- Ошибки сохранения больше не выдаются за успех; повреждённая база не заменяется пустой, сохраняется последняя корректная копия.
- Пустой пул нельзя включить; отключение автоматики отменяет текущую проверку. Контролируется здоровье резервного сервера.
- Стратегия по порядку выбирает первый доступный сервер; длительное сканирование имеет ограничение времени и продолжается со следующего кандидата.
- Порт меняется без завершения процесса; занятый порт вызывает откат.
- Обновление приватного GitHub через серверный токен, фиксацию SHA, проверку файлов и откат кода при неудачном запуске.
- Ограничены HTTP-запросы и распаковка ZIP; отклоняются небезопасные идентификаторы из резервных копий.
- Изменение активного узла подпиской отмечается кнопкой «Применить обновление».
- Исправлено распознавание статуса «не работает»; init-скрипт больше не завершает все процессы Node при отсутствии PID-файла.
- Локально: 79 успешных тестов и проверка входа в браузере. Установка и сетевые испытания на роутере ещё не выполнены; подробности в docs/TESTING-2.2.0.md.
