## Баги

### B01 — Фокус клавиатуры выходит из редактора подписки на фон

- Серьёзность: Medium; приоритет: P2. Версия 2.2.3, встроенный браузер, 1440×1000. Выход на BODY наблюдался также на 390×844.
- Предусловие: открыта форма редактирования подписки.
- Шаги: сфокусировать «Отмена» → Tab → Tab.
- Ожидание: фокус циклически переходит к первому элементу модального окна, фон недоступен.
- Факт: сначала BODY, затем `service-status-badge` («Работает») на фоновой странице. Окно продолжает отображаться.
- Влияние: пользователь клавиатуры теряет контекст диалога и может перейти к фоновым действиям. Фактическая активация фоновых кнопок в этом прогоне не выполнялась.
- Доказательство: наблюдение `document.activeElement`; скриншот `modal-escape.png` в приватном каталоге прогона подтверждает открытый тестовый редактор, но сам по себе не доказывает порядок фокуса.

### B02 — Escape не закрывает редактор подписки

- Серьёзность: Low; приоритет: P3. Воспроизведено дважды: 390×844 и 1440×1000.
- Шаги: открыть «Редактировать» → сфокусировать поле «Название» → Escape.
- Ожидание: окно закрывается без сохранения, фокус возвращается к вызвавшей его кнопке. Это ожидаемое стандартное поведение модального окна; отдельной спецификации Escape в проекте не обнаружено.
- Факт: заголовок «Настройки подписки» остаётся видимым. «Отмена» мышью закрывает окно.
- Влияние: неудобство при работе клавиатурой; обход — кнопка «Отмена».

### B03 — README отстаёт от текущего релиза

- Серьёзность: Low; приоритет: P3. Воспроизводится чтением текущего README.
- Шаги: сравнить README, `/api/data` и CHANGELOG.
- Ожидание: номер актуального релиза и ссылки на его проверки согласованы.
- Факт: README содержит версию 2.2.2, число 85 и ссылку на TESTING-2.2.2; панель работает на 2.2.3, существует отчёт TESTING-2.2.3.
- Влияние: пользователь получает устаревшие сведения о версии и объёме проверок.
