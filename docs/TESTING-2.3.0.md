# Проверка 2.3.0 — 05.10.2026

## Автоматические проверки

`node --test test/*.test.js`: 92 теста прошли, ошибок нет. Проверки покрывают подписки, маршрутизацию, автоматику, обновление, сохранение данных и управление диалогами.

## Интерфейс

На локальном стенде с демонстрационными данными проверены четыре основные вкладки при ширине 1440, 1024, 768, 390 и 320 px:

- вкладки имеют одинаковые размеры на каждой ширине;
- шапка сохраняет координаты при переключении вкладок;
- горизонтальное переполнение страницы отсутствует;
- светлые поверхности и читаемые статусы в списке подключений, маршрутизации, подписках и автоматике;
- раскрытый профиль маршрутизации и редактор JSON;
- редактор подписки на ширине 320 px: поля и кнопки помещаются в диалог;
- Tab удерживает фокус в диалоге, Escape закрывает его и возвращает фокус на кнопку редактирования;
- настройки, новая иконка шапки и ресурс favicon загружаются;
- ошибок JavaScript в журнале проверенной страницы нет.

Скриншоты README сняты на стенде с адресами example.com и синтетическими параметрами. Личные данные подписки не использовались.
